# 事業コンテキスト（Business Context）

壁打ちログから見えてきた、本人の事業の方向性・背景。
※「引っ越し・再構築」がこの事業に関わる可能性が高いため、別立てで整理。

## 現状 → 移行の方向性
- **やめる/見直す**
  - スマホ・パソコン教室の運営（今年いったん停止）
  - スクール向け教材制作事業（オワコン化の実感）
  - 教室で使っていた **教材利用料の支払い** を見直し/停止
  - Fable での自作教材（作れて感動したが、更新の手間が重すぎて断念 → 明鏡の無料サイト教材を中心に）
- **移行先の柱**
  - **作業会 ＋ 伴走サポートのサブスク** へ完全移行
  - 地域の小規模事業者向け **AI導入支援＆伴走サポート**
  - PC/AIをこれから覚えたい人向けの **伴走サポートクラス**
  - **個別コンサル**

## 顧客像
- 超初心者層が中心。例：「バスの接近情報が見れない」「タクシーアプリを教えて」「メルカリを教えて」「コンビニのネットプリントがわからない」
- 高額教材に騙されやすい層 → だからこそ伴走・作業会で守りたい、という動機

## 収益モデル（組み合わせ）
作業会を軸に以下を掛け合わせる：
- Brain教材の活用（アフィリエイト販売）
- 伴走サポート
- サブスク
- 個別コンサル
- 日常の困りごと解決

## 将来の拡張
- **AFP（ファイナンシャルプランナー）を復活** → 「これからのライフプランニングコンサル」へ
  - オンチェーン含めたグローバル資産運用
  - AIエージェント活用
  - 時間とお金を生み出すポートフォリオ設計

## 進め方
- まずは小さな作業会から開始 → 参加者の困りごとを聞きながら徐々に形にする
- 事業計画は「軍配スキル」で練り直す（作業会の内容・料金・継続サポート設計も見直し予定）
- 作業会の詳細案内は SNS 投稿のツリーで流す

## メモ / 用語の要確認
- **「軍配 / 軍配スキル」**: 事業計画や作業会の内容を見直すために使うツール/スキルらしい。正式名称・実体は要確認（音声入力での表記ゆれの可能性あり）。
- **明鏡**: 無料サイト教材の提供元と思われる。要確認。
