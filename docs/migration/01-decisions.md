## D-01: リポジトリの公開範囲は Private
- **決定**: `miyuk9/move` は Private（非公開）で運用する。
- **経緯**: 誤って Public にしてしまい、Private に戻す手順を確認した（元チャット01）。
- **手順**: Settings → Danger Zone → Change repository visibility → Make private → リポジトリ名を入力して確定。
- **状態**: 対応済み想定（要確認）。
