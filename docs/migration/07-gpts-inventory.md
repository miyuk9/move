# GPTs 棚卸し台帳（GPTs Inventory）

散らばっている GPTs を集約するための実行用ドキュメント。
→ 設計 D-04（相談窓口を一つにし、既存GPTsを外部の専門家として登録 → よく使う順に自前システムへ移管）の前段作業。
手順の詳細: [04-source-chats/07-gpts-inventory-howto.md](04-source-chats/07-gpts-inventory-howto.md)

## 集める3+1か所
1. ChatGPT「マイGPT」（自作GPTs）
2. ChatGPTの会話履歴（他人作GPTs、`Ctrl+K`/`Cmd+K`で検索）
3. Chrome/Edge/Safari のブックマーク（`@bookmarks` → ChatGPT/GPT/openai）
4. （徹底調査時）ChatGPTデータ書き出し（設定→データコントロール→エクスポート）

- **判断**: 主力（日常）/ 残す（特定用途）/ 試す（未評価）/ 削除候補（重複・用途不明）

## 実行手順（チェックリスト）
- [ ] WindowsのChromeブックマークを `@bookmarks` で確認
- [ ] Mac / Android が同じGoogleアカウントか確認（ブックマーク同期）
- [ ] Edge / Safari のブックマークも確認
- [ ] ChatGPT「マイGPT」を記録
- [ ] ChatGPT会話履歴を検索して他人作GPTを拾う
- [ ] 重複を統合
- [ ] 分類（発信/教室/教材/リサーチ/人生設計/開発）を付与
- [ ] 「主力」から順に、D-04の自前システムへ移管する計画を立てる

## この作業はAI（＝この Claude Code）に任せられる
人は「書き出し」だけ、残り9割はAIが処理できる半自動方式。
1. **人**: Chromeブックマークを書き出す（右上︙→ブックマークとリスト→ブックマークマネージャ→︙→エクスポート）＝ HTMLファイル
2. **人**:（任意・徹底調査時）ChatGPTのデータをエクスポート（ZIP）
3. **人**: その HTML / ZIP を、このリポジトリか Google Drive に置く（またはチャットに添付）
4. **私**: リンク抽出・重複統合・自作/他人作の区別・用途読み取り・分類・仕分け・台帳作成（スプレッドシート用CSV＋Obsidian索引）まで実行

- プライバシー注意: ChatGPTエクスポートには個人的な会話も含まれる。**まずブックマークHTMLだけ**で作り、履歴は後から追加が安全。
- 台帳完成後は、新しいHTMLを置くたびに「新規分だけ差分追記」する運用に自動化できる。
