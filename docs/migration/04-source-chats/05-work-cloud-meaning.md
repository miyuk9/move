# 元チャット 05: 「WORKのクラウド」ってどういう意味？

> 原文保存（壁打ちログ）。用語説明。現状のツール群が言及されているため、要点は 06-architecture.md「移行元（現状のツール）」に反映。

## 発言（本人）
WORKのクラウドってどういう意味？

## 回答（AI）
「WORKのクラウド」は文脈で意味が変わる。AI/PCの話なら主に次のどちらか。

### 1. クラウド（Cloud）＝インターネット上で作業すること
データやプログラムが自分のPCではなくネット上のサーバーにある状態。
- 例: ChatGPT / Claude / Google Drive / OneDrive / Canva / Notion
- メリット: どの端末からでも使える / 自動保存 / バックアップしやすい

### 2. ローカル（Local）との違い
- クラウド: データはネット上 / どの端末からでも / 共同編集しやすい
- ローカル: データは自分のPC内 / オフラインでも使える / 高速だがそのPCに依存

### あなたが作ろうとしている環境での整理
以前話していた ChatGPT / Claude / Obsidian / GitHub / OneDrive / Google Drive を組み合わせる場合：
- Obsidian … 基本はローカル
- OneDrive / GitHub … クラウドで同期
- ChatGPT・Claude … クラウドAI

### 補足
「WORKのクラウド」が特定画面に表示された言葉なら、スクショを送れば具体的に説明できる。
