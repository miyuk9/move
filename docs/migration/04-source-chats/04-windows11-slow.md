# 元チャット 04: Windows11の動きが重たい（メモリ）

> 原文保存（壁打ちログ）。作業PCの環境制約が読み取れるため、要点は 02-requirements.md / 03-open-questions.md にも反映。

## 発言（本人）
Windows11の動作が遅い、AIごりごり動かしてる、メモリの確認方法は？できる対策は？

## 回答（AI）
原因は1つのアプリではなく、**メモリ不足＋複数アプリの同時起動**。

画面上の状態：
- メモリ：86%（← 一番の原因）
- CPU：20%（現時点では問題小さめ）
- ディスク：2%（問題なし）

メモリを使っているもの：
1. Google Chrome：約833MB
2. Claude：約552MB
3. Discord：約240MB
4. Antimalware：約157MB
5. Slack、LINE、WhatsAppなど合計約250MB

ChromeとClaudeだけで約1.4GB、さらにDiscord・Slack・LINE・WhatsAppが常駐。Windows本体も使うので合計86%。

### 閉じてよい候補（使っていないものから「×」で終了）
- Discord / Slack / WhatsApp / LINE
- Claudeをアプリ版とブラウザ版で二重に開いているなら片方
- Chromeの不要なタブ
- ※ Antimalware Service Executable はWindowsのセキュリティ機能なので終了しない

### Chromeのタスクマネージャー
`Shift + Esc` でChrome専用タスクマネージャーが開く。「メモリ使用量」の大きい不要なタブを終了。
※「Google Chrome（15）」はタブ数ではなく、タブ＋拡張機能＋GPU処理＋バックグラウンド処理を合わせた15プロセス。

### 搭載メモリの確認
［パフォーマンス］→［メモリ］を開き、右上の 4.0GB / 8.0GB / 16.0GB / 32.0GB のどれかを確認。
- 4GB → AIを複数使うにはかなり不足
- 8GB → 同時起動を減らせば使えるが重くなりやすい
- 16GB → 別の常駐アプリやバックグラウンド処理も要確認
- **AIを複数使うなら32GBが安心**

今回の状態からは搭載メモリ4GBまたは8GBの可能性。パフォーマンス→メモリ画面を見れば、増設が必要か設定で改善できるか判断できる。

## 発言（本人）— Shift+Esc がわからない
「Shift + Esc でChrome専用タスクマネージャーが開く」がわからない。

## 回答（AI）— メニューから開く方法
キーボードではなくChromeのメニューから開くのが簡単：
1. Google Chromeを開く
2. 右上の「︙」（縦3点）をクリック
3. ［その他のツール］をクリック
4. ［タスク マネージャ］をクリック

小さな別画面が開くので：
1. ［メモリ使用量］の見出しをクリック
2. 数字の大きい順に並べる
3. 不要なページの名前をクリック
4. 右下の［プロセスを終了］をクリック

※「ブラウザ」「GPUプロセス」「拡張機能」など、よく分からないものは終了せず、**ページ名が分かる不要なタブだけ**を終了する。

キーボードの場合：左下付近のShiftキーを押したまま、左上のEscキーを1回押す（ほぼ同時に）。

## 発言（本人）— Chromeタスクマネージャーのスクショ＋「減らせそうですか」
（添付画像：Chromeタスクマネージャー「タブと拡張機能」の一覧）
- タブ: Windows11 メモリ確認方法 … 380,552K
- 拡張機能: MetaMask … 275,532K（＋サブフレーム 83,460K）
- 拡張機能: Braavos: Bitcoin & Starknet Wallet … 81,236K
- 拡張機能: Suiet | Sui Wallet … 52,768K
- 拡張機能: Claude … 33,152K
- ツール: プリロード済み UI レンダラ … 29,336K

## 回答（AI）— 拡張機能を減らせる
かなり減らせる。特にブラウザ拡張機能がメモリを使っている。

減らせる候補（暗号資産ウォレット系だけで合計 約490MB）：
- MetaMask：約359MB（拡張機能275MB＋サブフレーム83MB）
- Braavos Wallet：約81MB
- Sui Wallet：約53MB
- Claude拡張機能：約33MB

一番上の「Windows11 メモリ確認方法」タブ（今開いているこのChatGPT画面、約380MB）は今は閉じなくてよい。

### 一時的に止める
現在の画面で対象を選び右下の［タスクを終了］。ただしChrome再起動で再び動く可能性あり。
※ MetaMaskを使用中・送金操作中・接続中は止めない。

### 普段使わない拡張機能を無効化
Chrome右上「︙」→［拡張機能］→［拡張機能を管理］で、使っていないもの（MetaMask / Braavos / Sui Wallet / Claude拡張機能）をオフに。
- ウォレットは削除ではなく、まずスイッチをオフ。
- 削除する場合は復元用フレーズが確実に保管されていることを確認してから。
- 「ツール：プリロード済みUIレンダラ」（約29MB）はそのままでOK。

作業後、Windowsのタスクマネージャーでメモリが86%から何%まで下がるか確認。目標は通常時70%以下、重い作業中でも80%前後まで。

> メモ: 拡張機能から MetaMask / Braavos(Starknet) / Sui のウォレットを使用している。事業の将来方向「オンチェーン含めたグローバル資産運用」（05-business-context.md）と関連する可能性のある環境シグナル。
